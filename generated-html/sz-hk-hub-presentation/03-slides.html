Safety Guardrails安全护栏 — Two-Layer Architecture

Layer ① · Rule-Based规则层

Hard-coded sensitive keyword filter (SENSITIVE_TERMS)

Keywords: "绕过外汇", "套现", "洗钱", "违规开户", "避税", "非法"

Layer ② · LLM-BasedAI层

LLM compliance review + Amap location anti-hallucination verification

Checks: fabricated place names, missing return trip, non-compliant financial advice
