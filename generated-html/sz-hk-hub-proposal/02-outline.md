## 1. 封面：项目定位
- 主标题：SZ-HK Hub 深港跨境专业生活助手
- 副标题：开题报告 · Proposal
- 关键信息：跨境金融 / 文旅活动 / 政策通关
- 建议配图位：`[图1 港深双城天际线主视觉]`、`[图2 口岸/交通场景]`

## 2. 背景与痛点：双城生活的现实挑战
- 痛点一：政策与服务信息碎片化、更新慢
- 痛点二：实时数据缺失导致决策失误
- 痛点三：合规与风险边界不清晰
- 建议图示：`[图3 港深双城路径与痛点分布示意]`

## 3. 目标与定位：为什么要做“专业 Agent”
- 定位：面向跨境高净值生活与决策的垂直助手
- 目标：准确、实时、合规、可验证
- 关键句：从“能回答”升级到“能决策”

## 4. 用户画像与核心场景
- 画像 1：跨境金融开户与资产配置需求
- 画像 2：高频文旅活动与展会参与者
- 画像 3：跨境通勤与商务人群
- 建议配图位：`[图4 用户场景实拍]`

## 5. 核心功能总览
- 跨境金融导航（RAG + 合规提示）
- 活动/情报自动化处理（多模态解析）
- 实时决策支持（汇率/口岸/港铁）

## 6. 技术架构总览
- 多智能体协作（Planner + Verifier）
- 高级 RAG（动态数据源）
- MCP 协议连接外部工具
- 安全护栏与敏感词过滤

## 7. Agent 工作流与协作机制
- 任务拆解 → 工具调用 → 自我审查 → 输出建议
- 核心优势：可追溯、可纠错、可解释

## 8. RAG 数据源与评估指标
- 数据源：港府、银行、港铁、论坛等动态信息
- 指标：Hit Rate / MRR 检索质量
- 建议配图位：`[图5 数据源入口或网页截图]`

## 9. MCP 工具层与实时决策能力
- 实时汇率、口岸人流、路径规划
- 形成“跨境决策工具箱”
- 建议配图位：`[图6 实时数据可视化]`

## 10. TDD-for-AI 测试策略
- 检索准确性测试
- Agent 行为路径测试
- Ollama 回退测试

## 11. 里程碑与交付计划
- 10 周节奏：数据 -> 架构 -> 集成 -> 测试 -> 报告
- 交付物：代码库、Web 应用、技术报告

## 12. 风险与收束
- 风险：数据更新、合规边界、实时性波动
- 应对：版本化数据、规则前置、监控报警
- 结束语：请支持开题与资源协同
