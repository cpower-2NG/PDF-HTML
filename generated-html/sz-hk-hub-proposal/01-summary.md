# 摘要

## 题目
SZ-HK Hub（深港跨境专业生活助手）开题报告

## 主题
跨境专业生活助手 · LLM + RAG + MCP 多智能体

## 受众
课程导师 / 评审老师 / 项目组同学

## 汇报目标
基于深港“双城生活”真实痛点，说明为何需要垂直领域 Agent，并展示核心功能、技术架构、合规策略与测试计划，争取开题认可与资源支持。

## 核心结论
通用 LLM 难以覆盖跨境实时政策与合规要求，必须以“多智能体 + 高级 RAG + MCP 实时工具 + 安全护栏”构建专业决策助手。

## 必含内容落点
- 背景痛点与用户需求
- 产品定位与核心功能
- 技术架构与数据源
- 测试策略与风险控制
- 里程碑与预期成果

## 呈现策略
- 港深双城视觉元素（双城天际线、口岸/港铁、跨境路径）。
- 风格新颖温和、信息密度适中。
- 每页一个主观点，图示优先用 SVG。
